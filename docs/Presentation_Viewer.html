Slide 1 Abstract & Executive Summary 🎤 Presenter: Member 1
  • Project Summary: CineMatch is a full-stack movie recommendation web application built with HTML, CSS, JavaScript, PHP 8.1, and MySQL, hosted on AWS EC2 with continuous integration via Jenkins.
  • Software Metrics Mandate: Integrating empirical metrics into Agile sprints to eliminate technical debt across static code size, control complexity, database execution, performance, defects, and test coverage.
Slide 2 Problem Statement & Research Questions 🎤 Presenter: Member 1
  • Problem Statement: Modern PHP web applications suffer from unmonitored code bloat, high cyclomatic complexity, and slow SQL execution under load.
  • Q1: How does refactoring functions with high Cyclomatic Complexity V(G) impact the overall Maintainability Index (MI)?
  • Q2: What is the quantitative relationship between unit test coverage and post-release defect density?
  • Q3: How do database index optimization metrics translate into page load speed improvements?
Slide 3 Literature Survey: 5 Recent Research Papers (2024–2025) 🎤 Presenter: Member 2
Author & Year Contribution Gap Identified
Al-Maimani et al. (2024) Automated Maintainability & Complexity Evaluation in Agile CI/CD Pipelines Evaluates static code metrics only during build time, ignoring database query latency and cloud infrastructure response times.
Sharma & Kumar (2024) ML-Based Defect Density Prediction using Code Coverage & Cyclomatic Complexity Requires extensive historical bug datasets and does not offer real-time feedback during active sprint commits.
Chen et al. (2025) Empirical Database Query Performance & Index Optimization Framework for Web Apps Focuses strictly on relational database schema metrics without correlating them to frontend user page load speed.
Kowalski & Zhang (2024) Continuous Quality Gates Integration using Jenkins & SonarQube in Agile Frameworks Lacks unified metric thresholds that combine static maintainability indices with dynamic load throughput.
Patel et al. (2025) Impact of Continuous Refactoring on Technical Debt & Code Coverage in Web Applications Evaluates refactoring manually post-release rather than dynamically enforcing quality gates in DevOps pipelines.
Slide 4 Software Metrics Tool Descriptions (All 7 Metrics) 🎤 Presenter: Member 3

1. Lines of Code (LOC)

Tools: PHPLOC / SonarQube
Physical & Logical LOC. Target: < 300 LLOC per file.

2. Cyclomatic Complexity

Tools: PHP_CodeSniffer / PHPMD
V(G) = E - N + 2P. Target: V(G) ≤ 10.

3. Maintainability Index

Tools: PHP Metrics / Radon
MI Formula combining Halstead V, V(G), LLOC. Target MI > 80.

4. Database Metrics

Tools: MySQL EXPLAIN / Perf Schema
Query execution time (<30ms) & Index Hit Ratio (>95%).

5. Performance Metrics

Tools: ApacheBench / Lighthouse
TTFB (<150ms), Page Load (<1.5s), Throughput (>200 req/s).

6. Defect Density

Tools: GitHub Issues / Azure DevOps
Bugs / KLOC. Target < 2.0 defects per 1000 LOC.

7. Code Coverage

Tools: PHPUnit + Xdebug
Line & Branch coverage percentage. Target > 80% line coverage.

Slide 5 System Architecture & Jenkins Pipeline Workflow 🎤 Presenter: Member 2
  • 3-Tier Layering: Presentation Layer (HTML/JS) → Application Layer (Apache/PHP) → Data Layer (MySQL).
  • Automated Jenkins Pipeline: GitHub Commit → Static Code Analysis (PHPLOC/V(G)) → PHPUnit Coverage Test → AWS EC2 Deployment.
